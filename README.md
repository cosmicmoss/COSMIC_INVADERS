# COSMIC INVADERS

A browser-based 3D space shooter built with Three.js — no build tools, no dependencies, single HTML file.

## Play

Open `index.html` in any modern browser, or visit the GitHub Pages link.

## Features

- 🚀 **Space combat** — wave-based enemy formations, boss battles (Zeong / Psycho Gundam / Gipsy Danger / R01 Mech)
- 🌲 **Forest planet** — on-foot third-person action, speeder bike chase, dungeon rescue
- ❄️ **Ice planet** — 5-phase campaign: infiltration → snow-trooper combat → cryo-valley → base raid → AT-RT walker battle + escape
- 🔥 **Fire planet** — corona dragon combat + on-foot Fire Dragon boss battle (beam shield + ice beam + saber finisher) → unlocks ship flamethrower
- 🏰 **Fortress assault** — **Star Wars–style fleet battle**: 4 capital ships (2 Imperial Star Destroyers + 2 Rebel Cruisers) exchange turbolaser fire in the far background → break through 12 TIE fighters to enter the trench → pursuit fighters + **4 formation allies** → progressive speed ramp → space-station interior → **Shield Generators ×2** → **EXECUTOR-CLASS DESTROYER boss** (turbolaser salvo / TIE deploy) → pulsing reactor core (HP×2) + chain explosions → **~8min final showdown**
- ⚔️ **ARMADA — 銀河大艦隊決戦** — **10-ship background fleet** (6 Imperial Star Destroyers + 4 Rebel Cruisers) wage all-out war → **5-phase campaign**: Fighter Screen (25 kills, TIE waves every 12s) → **Escort Destroyer Alpha** (HP60, turbolaser salvo) → **Escort Destroyer Beta** (HP60, turbolasers + **ion cannon** — 4s weapon disable) → Armada Clash (30 kills, double spawn rate) → **Titan-Class Dreadnought** (6 independently-destroyable weapon systems: Port Turrets ×2 / Starboard Pods ×2 / Ventral Sweep Cannon / Bridge; **RAGE MODE** at 50% HP; bridge locked until outer systems destroyed) → chain explosions → escape → **~8.5 min epic showdown**
- 🤼 **Space Colosseum** — hyperdrive fails mid-jump → captured by pirates → jail cell → fight 8 monsters (CHOP / Giant Swing / Frankensteiner); ring weapons auto-pickup; **audience energy balls** thrown ringside every 18-30s → catch for +2 HP; ring-outs → **spike impalement** + BBQ scene + money burst; **2520-person animated crowd** (7 tiers, constant bob + sway, ~5× density) + **POP BGM** + **constant crowd ambient noise** (cheers / heckles) + **crowd roar on technique hits**; grapple shouts; monster attack voices; eel crackle pre-shock; **boxer pilot 2× scale** with boxing helmet + gloves + boots + forest-quality joint animation + **orange back panel** for front/back orientation; **monster joint upgrades** (tengu/mantis/predator/queen — forearm groups + lower-leg groups + elbow/knee spheres); **GORGON boss** — multi-joint kaiju with 5-segment sinusoidal tail, 3-segment neck chain, 3-part arms/legs with claws, animated jaw; **TAILSHOW intimidation walk** (turns back to player, waves tail); Giant Swing ring-out → **GORGON flies out of arena** → kaiju BBQ celebration + crowd erupts; **SLAG REBORN secret wave** — after GORGON, SLAG returns 3.2× scale dual-wielding axes for a final grudge match → defeat unlocks friendship ending: baby alien freed + **"★ THE GALAXY IS AT PEACE ★"** cinematic with confetti + money burst + crew escape; **player–enemy + enemy–enemy collision** — no clipping through opponents
- 🚀 **Hyperspace jump** — asteroid belt → hyperdrive failure (ice planet arc) or Millennium Falcon–style warp → docking
- ❄️ **Ice planet auto-door** — hangar entrance slides open automatically when AT-RT arrives
- ⚡ **Magnet Coating** — post-colosseum upgrade; beams gently home in on enemies; unlocked via bridge emergency → mod bay → 5-fighter V-formation launch cinematic
- 🎬 **Story ending** — character epilogue text cards → **cyberpunk wireframe character parade** (7 cast members, neon-lit, orbiting camera) → TO BE CONTINUED teaser → "COSMIC INVADERS 2" title reveal
- 🎵 **Procedural audio** — full BGM with orchestral boss theme + 3-movement ending orchestra, all SFX synthesized via Web Audio API
- 🎮 **Keyboard + touch controls**

## Controls

| Key | Action |
|-----|--------|
| WASD / Arrow keys | Move |
| Space | Fire laser / shoot |
| M | Missiles |
| N | Napalm |
| Shift | Boost / Beam Shield (on foot) / Flamethrower (if unlocked) |
| ESC | Options |
